# 🧠 AI Health Analytics Platform

An advanced machine learning-based web application that predicts health risks such as Heart Disease, Diabetes, and Lung Disease.

## 🚀 Features
- Multi-disease prediction using ML models
- Interactive dashboard with visual analytics
- Health score calculation
- AI-based health assistant
- PDF report generation
- Modern UI using Streamlit

## 🛠 Tech Stack
- Python
- Streamlit
- Scikit-learn
- Plotly
- ReportLab
